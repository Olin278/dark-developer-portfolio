AI application development

VOIDUS — Personal AI Computer Agent

VOIDUS brings AI conversation, voice interaction, memory, and computer workflows into one desktop assistant. It is designed to reduce the need to switch between separate tools by letting users describe tasks in natural language, retrieve relevant context, and coordinate computer actions with verification.

Key focus

  • Natural-language interaction with an AI assistant.
  • Real-time voice conversations.
  • Contextual recall of relevant conversation history.
  • A unified workflow for planning and carrying out computer tasks.
  • Verification of actions so the assistant can report whether they actually succeeded.

AI & cybersecurity

MINT Security — AI-Assisted Cybersecurity

MINT Security is an AI-assisted cybersecurity project focused on threat analysis, firewall defense, and self-healing security workflows. It aims to help users move beyond alerts alone by identifying suspicious activity, supporting controlled defensive responses, and checking whether recovery actions restore a safer security state.

Key focus

  • Analysis of suspicious activity and potential threats.
  • Firewall and network-defense workflows.
  • Controlled response to detected security issues.
  • Recovery and verification after remediation.
